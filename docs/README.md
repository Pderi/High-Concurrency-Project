# docs 目录说明

按用途分为三类，避免设计稿、规范与落地讲解混在一起。

| 目录 | 用途 | 典型读者 |
| --- | --- | --- |
| [规范/](./规范/) | 编码与架构约束、通用方法论（跨项目可复用） | 写代码前对齐规则 |
| [设计/](./设计/) | 本项目开发前的需求、库表、技术方案、业务规则、概要设计、分期计划与扩展蓝图 | 定范围、评审、排期 |
| [讲解/](./讲解/) | 结合**当前代码**的链路说明与阶段专项讲解 | 联调、演示、新人上手 |
